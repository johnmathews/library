Which dashboard layout by default

Decided 2026-11-27: B · Rows, on every device. The other three stay in the Layout menu.

The four layouts from the trial, on the same ten invented documents with the default fields (type, from, tags, date, language, status).

  1. Each option shows a desktop at 1440px and a phone at 375px, in light and dark. Use Open full size to see one at your screen's own width, on your phone too.
  2. The table needs a results area of about 912px with six fields. Below that, including phones and tablets in portrait, it shows as the list. A desktop gets the table from a window about 1230px wide with the sidebar open, or about 1060px with it collapsed.
  3. The default can differ by device, for example the list on a phone and the table on a desktop. Choosing C already gives that.

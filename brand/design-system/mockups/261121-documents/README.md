# Documents on Quiet

**Question:** how a document type's colour shows on a tile, now that Quiet's cards have no outline
to paint. The rest of the page shows the Documents screen, a document's detail and the phone view
restyled onto Quiet per the approved spec (`docs/superpowers/specs/2026-11-21-brand-design.md`);
those parts are previews, not questions.

**Status:** decided (2026-11-21)

**Link:** https://claude.ai/artifact/L2C7UVqq4fwdDWgXM6cLpb

## Options

- **A. A band across the top.** A 4px band in the type's colour along the tile's top edge.
  Recommended: scans like today's coloured borders across a full grid, without outlining the card.
- **B. A stripe down the left.** A 4px stripe down the left edge, like a file tab. Easy to miss
  beside the thumbnail.
- **C. A dot in the type chip.** The quietest, closest to Finances' category chips, but not
  visible across the grid at a glance.

All three use Quiet's chart palette (`category-1…5`) as the default type colours instead of
today's sky, green, violet, amber and red. Each clears 3:1 on a tile in light; the letter's purple
is 3.1:1 in dark.

## Decision

**A · A band across the top**, 2026-11-21, the recommended option. The owner also chose Quiet's
chart palette (`category-1…5`) as the default type colours over today's set; stored per-type picks
are kept.
